## 1. Fibonacci Numbers

### ✅ Concept Summary

* **Type**: 1D DP
* **Approach**: Top-down with memoization and Bottom-up with tabulation

### 🔷 Why DP?

* Subproblems: `fib(n-1)`, `fib(n-2)` appear repeatedly
* Changing variable: `n`
* 1D DP is enough since we track one value

### 💡 Code Explanation

* Base: `fib(0) = 0`, `fib(1) = 1`
* Recursive: `fib(n) = fib(n-1) + fib(n-2)`

### 🧠 Optimizations

* Use 2 variables instead of array for constant space

### ✅ Code (Bottom-up)

```js
function fib(n) {
  if (n <= 1) return n;
  let a = 0, b = 1;
  for (let i = 2; i <= n; i++) {
    const temp = a + b;
    a = b;
    b = temp;
  }
  return b;
}
```

## 2. Climbing Stairs

### ✅ Concept Summary

* **Type**: 1D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* Each step can be reached from `n-1` or `n-2`
* Changing variable: `n`

### 💡 Code Explanation

* `dp[n] = dp[n-1] + dp[n-2]`

### 🧠 Optimizations

* Use 2 variables like Fibonacci

### ✅ Code

```js
function climbStairs(n) {
  let a = 1, b = 1;
  for (let i = 2; i <= n; i++) {
    const temp = a + b;
    a = b;
    b = temp;
  }
  return b;
}
```

## 3. House Robber

### ✅ Concept Summary

* **Type**: 1D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* At index `i`, choose max of (rob `i` + dp\[i-2]) or skip `i` (dp\[i-1])
* Changing variable: index in array

### 💡 Code Explanation

* `dp[i] = max(dp[i-1], nums[i] + dp[i-2])`

### 🧠 Optimizations

* Use 2 variables

### ✅ Code

```js
function rob(nums) {
  let prev1 = 0, prev2 = 0;
  for (let num of nums) {
    const temp = Math.max(prev1, prev2 + num);
    prev2 = prev1;
    prev1 = temp;
  }
  return prev1;
}
```

## 4. Coin Change

### ✅ Concept Summary

* **Type**: 1D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* Try all coins for amount `i`
* Changing variable: `amount`

### 💡 Code Explanation

* For every coin, update `dp[i] = min(dp[i], dp[i - coin] + 1)`

### ✅ Code

```js
function coinChange(coins, amount) {
  const dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;
  for (let coin of coins) {
    for (let i = coin; i <= amount; i++) {
      dp[i] = Math.min(dp[i], dp[i - coin] + 1);
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount];
}
```

## 5. Longest Increasing Subsequence (LIS)

### ✅ Concept Summary

* **Type**: 1D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* For each index `i`, find previous `j < i` where `arr[j] < arr[i]`
* Changing variable: index `i`, compare with past `j`

### 💡 Code Explanation

* `dp[i] = max(dp[i], dp[j]+1)`

### ✅ Code

```js
function lengthOfLIS(nums) {
  const dp = new Array(nums.length).fill(1);
  for (let i = 1; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
      }
    }
  }
  return Math.max(...dp);
}
```

## 6. Longest Common Subsequence (LCS)

### ✅ Concept Summary

* **Type**: 2D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* Compare characters of both strings at `i` and `j`
* Changing variables: indices `i`, `j` of both strings

### 💡 Code Explanation

* If match: `dp[i][j] = 1 + dp[i-1][j-1]`
* Else: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

### ✅ Code

```js
function longestCommonSubsequence(text1, text2) {
  const m = text1.length, n = text2.length;
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) {
        dp[i][j] = 1 + dp[i - 1][j - 1];
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }
  return dp[m][n];
}
```

## 7. Edit Distance

### ✅ Concept Summary

* **Type**: 2D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* Compare each character of both strings
* Choices: Insert, Delete, Replace

### 💡 Code Explanation

* `dp[i][j] = min(insert, delete, replace)`

### ✅ Code

```js
function minDistance(word1, word2) {
  const m = word1.length, n = word2.length;
  const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

  for (let i = 0; i <= m; i++) dp[i][0] = i;
  for (let j = 0; j <= n; j++) dp[0][j] = j;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      } else {
        dp[i][j] = 1 + Math.min(
          dp[i - 1][j],     // delete
          dp[i][j - 1],     // insert
          dp[i - 1][j - 1]  // replace
        );
      }
    }
  }
  return dp[m][n];
}
```

## 8. 0/1 Knapsack

### ✅ Concept Summary

* **Type**: 2D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* For each item: take or skip
* Changing variables: `i` (item index), `w` (capacity)

### 💡 Code Explanation

* `dp[i][w] = max(dp[i-1][w], value + dp[i-1][w - weight])`

### ✅ Code

```js
function knapsack(weights, values, capacity) {
  const n = weights.length;
  const dp = Array.from({ length: n + 1 }, () => Array(capacity + 1).fill(0));

  for (let i = 1; i <= n; i++) {
    for (let w = 0; w <= capacity; w++) {
      if (weights[i - 1] <= w) {
        dp[i][w] = Math.max(dp[i - 1][w], values[i - 1] + dp[i - 1][w - weights[i - 1]]);
      } else {
        dp[i][w] = dp[i - 1][w];
      }
    }
  }
  return dp[n][capacity];
}
```

## 9. Subset Sum

### ✅ Concept Summary

* **Type**: 2D DP
* **Approach**: Bottom-up

### 🔷 Why DP?

* Decide to include or exclude each element for given sum

### ✅ Code

```js
function subsetSum(nums, target) {
  const n = nums.length;
  const dp = Array.from({ length: n + 1 }, () => Array(target + 1).fill(false));
  for (let i = 0; i <= n; i++) dp[i][0] = true;

  for (let i = 1; i <= n; i++) {
    for (let sum = 1; sum <= target; sum++) {
      if (nums[i - 1] <= sum) {
        dp[i][sum] = dp[i - 1][sum] || dp[i - 1][sum - nums[i - 1]];
      } else {
        dp[i][sum] = dp[i - 1][sum];
      }
    }
  }
  return dp[n][target];
}
```

## 10. Unique Paths (Matrix DP)

### ✅ Concept Summary

* **Type**: 2D DP Grid
* **Approach**: Bottom-up

### ✅ Code

```js
function uniquePaths(m, n) {
  const dp = Array.from({ length: m }, () => Array(n).fill(1));

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
    }
  }
  return dp[m - 1][n - 1];
}
```

## 11. Min Path Sum (Matrix DP)

### ✅ Code

```js
function minPathSum(grid) {
  const m = grid.length, n = grid[0].length;
  const dp = Array.from({ length: m }, () => Array(n).fill(0));
  dp[0][0] = grid[0][0];

  for (let i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];
  for (let j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
    }
  }
  return dp[m - 1][n - 1];
}
```

## 12. Palindrome Partitioning (Min Cuts)

### ✅ Concept Summary

* **Type**: 1D DP + Memoization for palindrome

### ✅ Code

```js
function minCut(s) {
  const n = s.length;
  const dp = new Array(n).fill(0);
  const isPalindrome = Array.from({ length: n }, () => Array(n).fill(false));

  for (let i = 0; i < n; i++) {
    let minCut = i;
    for (let j = 0; j <= i; j++) {
      if (s[j] === s[i] && (i - j <= 2 || isPalindrome[j + 1][i - 1])) {
        isPalindrome[j][i] = true;
        minCut = j === 0 ? 0 : Math.min(minCut, dp[j - 1] + 1);
      }
    }
    dp[i] = minCut;
  }
  return dp[n - 1];
}
```
