Here is a crisp, concept-by-concept breakdown of these essential JavaScript pillars.

---

## 1. Variables

Variables are containers for storing data values. JavaScript uses `var`, `let`, and `const`, each with different rules regarding reassignment and scope.

* `var`: Old school, function-scoped, can be redeclared and reassigned.
* `let`: Modern, block-scoped, can be reassigned but *not* redeclared.
* `const`: Modern, block-scoped, cannot be reassigned or redeclared (though object properties *can* be mutated).

### Example

```javascript
const taxRate = 0.15; // Cannot be changed
let totalAmount = 100; // Can be changed
totalAmount = 120; 

if (true) {
    var legacy = "I leak outside this block";
    let modern = "I stay inside this block";
}
console.log(legacy); // Works | output- I leak outside this block
// console.log(modern); // Throws ReferenceError

```

---

## 2. Scope

Scope determines the accessibility (visibility) of variables. JavaScript has three types: **Global** (accessible everywhere), **Function** (accessible only inside the function), and **Block** (accessible only inside `{ }` like loops or if-statements).

### Example

```javascript
let globalVar = "Global";

BlockScopeExample();

function FunctionScopeExample() {
    let functionVar = "Function Only";
    console.log(globalVar); // Works
}

if (true) {
    let blockVar = "Block Only";
    var notABlock = "I ignore blocks";
}
// console.log(blockVar); // Error
console.log(notABlock); // Works

```

---

## 3. Hoisting

Hoisting is JavaScript's default behavior of moving declarations to the top of the current scope before code execution.

* `var` is hoisted and initialized as `undefined`.
* `let` and `const` are hoisted but **not initialized** (they sit in a "Temporal Dead Zone" until execution hits their line).
* Function declarations are hoisted fully (name and body).

### Example

```javascript
console.log(hoistedVar); // undefined (due to var hoisting)
var hoistedVar = "Hello";

// console.log(hoistedLet); // Throws ReferenceError (Temporal Dead Zone)
let hoistedLet = "Hi";

greet(); // Works perfectly because function declarations are fully hoisted
function greet() {
    console.log("Good morning!");
}

```

---

## 4. Closures

A closure is the combination of a function bundled together with references to its surrounding state (the **lexical environment**). In simple terms, a closure gives an inner function access to the outer function's scope even after the outer function has finished executing.

### Example

```javascript
function createCounter() {
    let count = 0; // "Private" variable
    return function() {
        count++; // Remembers and accesses 'count'
        return count;
    };
}

const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2

```

## 5. `this` Keyword

The `this` keyword refers to the object that is currently executing the code (the execution context). Its value depends entirely on *how* a function is called:

* **Method invocation:** Points to the object before the dot.
* **Simple function call:** Points to the `window` (or `undefined` in strict mode).
* **Arrow functions:** Do not have their own `this`; they inherit it lexically from the surrounding scope.

### Example

```javascript
const user = {
    name: "Alice",
    greet() {
        console.log(`Hi, I'm ${this.name}`); // 'this' is 'user'
    },
    delayGreet() {
        setTimeout(() => {
            console.log(`Hi, I'm ${this.name}`); // Arrow function inherits 'this' from delayGreet
        }, 100);
    }
};

user.greet(); // "Hi, I'm Alice"
user.delayGreet(); // "Hi, I'm Alice"

```

## 6. Prototype

Every JavaScript object has a hidden, built-in property called its **Prototype** (accessible via `Object.getPrototypeOf(obj)` or `__proto__`). The prototype is simply an object from which other objects inherit properties and methods.

### Example

```javascript
const animal = {
    eats: true
};

// Create a new object with 'animal' as its prototype
const rabbit = Object.create(animal);

console.log(rabbit.eats); // true (inherited from animal)
console.log(rabbit.hasOwnProperty('eats')); // false (it's not its own property!)

```

---

## 7. Prototype Chain

When you try to access a property or method on an object, JavaScript first looks at the object itself. If it doesn't find it, it looks at the object's prototype, then the prototype's prototype, and so on, traveling up the **Prototype Chain** until it either finds it or hits `null`.

### Example

```javascript
const grandparent = { hair: "gray" };
const parent = Object.create(grandparent);
const child = Object.create(parent);

// JavaScript looks at child -> parent -> grandparent and finds "gray"
console.log(child.hair); // "gray"
// JavaScript looks all the way up to Object.prototype, doesn't find it, returns undefined
console.log(child.wings); // undefined

```

## 8. Classes

Introduced in ES6, JavaScript classes are primarily syntactical sugar over the existing prototype-based inheritance. They provide a much cleaner, cleaner syntax to create objects and handle inheritance.

### Example

```javascript
class Car {
    constructor(brand) {
        this.brand = brand;
    }
    drive() {
        return `${this.brand} goes vroom!`;
    }
}

class ElectricCar extends Car {
    constructor(brand, batteryLife) {
        super(brand); // Calls the parent constructor
        this.batteryLife = batteryLife;
    }
}

const myTesla = new ElectricCar("Tesla", "100%");
console.log(myTesla.drive()); // "Tesla goes vroom!" (Inherited method)

```

## 9. Modules (ESM vs. CommonJS)

Modules split your code into separate, maintainable files. There are two major module standards in JavaScript:

* **CommonJS (CJS):** Node.js default historical standard. Uses `require()` and `module.exports`. Synchronous.
* **ECMAScript Modules (ESM):** The official browser/modern standard. Uses `import` and `export`. Asynchronous.

### Example Comparison

| Feature | CommonJS (Node.js) | ESM (Modern/Browser) |
| --- | --- | --- |
| **Export Syntax** | `module.exports = { math };` | `export const math = ...;` |
| **Import Syntax** | `const math = require('./math');` | `import { math } from './math.js';` |
| **Loading** | Synchronous | Asynchronous |

```javascript
// --- mathJS.js (ESM Example) ---
export function add(a, b) { return a + b; }

// --- appJS.js (ESM Example) ---
import { add } from './mathJS.js';
console.log(add(2, 3)); // 5

```
